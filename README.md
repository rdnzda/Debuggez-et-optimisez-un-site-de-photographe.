# Nina Carducci – debugging and optimizing a photographer's website

**OpenClassrooms "Web Integrator" program – project 4.**

An existing portfolio website for a photographer (Nina Carducci, portraits and events in Bordeaux) had bugs and poor performance. The goal was to fix it and improve its performance, accessibility and SEO.

## What I did

- **Debugging**: fixed the bugs of the JavaScript photo gallery (`maugallery.js`)
- **Performance**: converted and resized images to WebP, with several sizes for responsive loading
- **SEO**: added a meta description and Open Graph tags, plus structured data (JSON-LD) for the local business
- **Accessibility**: added meaningful `alt` texts and ARIA attributes

## Tech stack

- HTML5, CSS3, JavaScript (jQuery plugin `maugallery.js`)
- Bootstrap

## Getting started

No build step: open `index.html` in a browser.
